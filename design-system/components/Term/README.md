# Term

An inline jargon explainer: the word is a button with a dotted underline; pressing it shows a plain-English definition right below the sentence. Answers the workshop's "idiot's guide to lingo".

## Props
`children` (the word as written), `definition`, `expansion` (for acronyms, e.g. "Personal Education Plan").

## Usage
Use on the first mention of a term on a page, not every mention. Pull definitions from the same list as the Glossary so they never disagree. In the Pupil Zone, define every acronym.
