# BackToTop

A "Back to top" link that appears once the reader has scrolled past `threshold` px.

## Props
`href` ('#top'), `threshold` (600), `alwaysVisible` (false), `fixed` (false — pins bottom-right), `children`.

## Usage
Long guidance pages only. Put `id="top"` on the skip-link target or the page heading. Prefer the in-flow version at the end of content; use `fixed` only on very long pages.
