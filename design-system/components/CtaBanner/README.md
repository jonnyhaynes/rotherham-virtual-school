# CtaBanner

A branded call-to-action or statement band with the corner arcs from the brand. The `ending` variant is the branded page ending before the footer.

## Props
`title`, `text`, `action` (`{label, href}`), `icon`, `variant` (`'brand' | 'navy' | 'ending'`), `decoration` (true), `headingLevel` (2), `id` (unique per page when used twice).

## Usage
One per page, near the end. Brand and ending sit on `pale-blue`; navy uses an inverse button. Keep the title to one sentence.
