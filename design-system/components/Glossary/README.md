# Glossary

A searchable list of terms and acronyms with plain-English definitions ("Words you might hear"). Filters as you type and announces the count.

## Props
`terms` (`{term, expansion?, definition, href?, linkLabel?}[]`, sorted A to Z automatically), `heading`, `headingLevel`, `searchable` (true), `searchLabel` ('Find a word'), `askHref` (shown when nothing matches).

## Usage
One list for the whole site, managed in the CMS, also feeding `Term`. Definitions are one or two short sentences, written so a 12-year-old understands them. For a long list add `AzIndex` above it.
