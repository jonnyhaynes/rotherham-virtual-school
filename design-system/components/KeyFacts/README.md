# KeyFacts

Term–value pairs in a definition list: key facts panels, eligibility summaries, definition lists and summary lists.

## Props
`items` (`{term, value}[]` — value may be a node), `title`, `icon`, `variant` (`'panel' | 'list'`).

## Usage
Use `panel` near the top of guidance to answer "who, what, how" at a glance; `list` for longer definition lists and check-your-answers summaries. Stacks to one column under 500px.

## GOV.UK
`list` is equivalent to `govuk-summary-list` without row actions.
