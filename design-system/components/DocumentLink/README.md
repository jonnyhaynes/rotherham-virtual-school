# DocumentLink

A downloadable file — guidance document, template, policy — with its type, size, pages and last update. Build resource collections by listing several in a `Grid` or stack.

## Props
`title`, `href`, `fileType` ('PDF'), `fileSize`, `pages`, `description`, `updated`, `download`, `accessibleHref` (request an accessible format), `variant` (`'card' | 'compact'`).

## Usage
Prefer an HTML page to a PDF. When a file is needed, always state its format and size in the link (included for screen readers automatically) and offer an accessible format.

## GOV.UK
Equivalent to the GOV.UK attachment pattern.
