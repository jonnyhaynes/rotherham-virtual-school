# KeyDates

Upcoming deadlines and dates as calendar tiles; past dates are muted and the next one is highlighted with a "Next" tag.

## Props
`dates` (`{date: ISO, label, detail?, href?}[]`, sorted), `heading` ('Key dates'), `highlightNext` (true), `today` (ISO, defaults to now).

## Usage
PEP and funding deadlines, term dates, reporting windows. Keep labels to the action ("Autumn PEP deadline"). The year is included for screen readers.
