# AzIndex

An A to Z of terms or services: a letter bar (letters without entries are shown but not linked) and a section per letter.

## Props
`groups` (`{letter, items: {label, href, description?}[]}[]`), `label` ('A to Z'), `idPrefix` ('az-').

## Usage
Use for the glossary of care and education terms (PEP, PP+, SGO, designated teacher) and service directories. Keep descriptions to one plain-English clause.
