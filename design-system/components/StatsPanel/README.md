# StatsPanel

Up to five headline figures with labels, a short description and a source.

## Props
`stats` (`{value, label, description?}[]`), `heading`, `source`, `variant` (`'default' | 'navy'`).

## Usage
Only published figures — from the annual report, DfE data or cited research — always with a `source`. No decorative or rounded-up "filler" numbers. The value is marked up after its label (`dt`/`dd`), so it reads "of children in care: 63%". The example uses the figures cited on the live Speech and language therapy page.
