# Illustration

A container for the brand illustrations: rounded frame on the audience's soft tint, optional caption.

## Props
`name` (`'home' | 'children' | 'parents-carers' | 'schools'` from the Illustrations group) or `src`, `alt` ('' — decorative by default), `variant` (`'frame' | 'circle' | 'bleed'`), `audience`, `caption`.

## Usage
Illustrations show young people from behind, looking forward — keep that: no faces of real children, no stock photos of children in care. Use the matching audience illustration on each audience landing page.
