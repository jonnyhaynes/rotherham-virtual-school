# Accordion

Collapsible sections for FAQs and reference content, with "Show all sections".

## Props
`items` (`{heading, summary?, content, open?}[]`), `showAll` (true), `headingLevel` (2).

## Usage
Only when people need a few sections, not all — never for essential steps. Headings must make sense on their own. Use `Details` for a single optional explanation.

## GOV.UK
Mirrors `govuk-accordion` (button inside the heading, `aria-expanded`, show/hide all).
