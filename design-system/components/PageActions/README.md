# PageActions

Copy link, share and print for guidance pages, with a live "Link copied" confirmation. Covers copy-to-clipboard, share and print actions.

## Props
`actions` (`['copy','share','print']`), `url` (defaults to the current page), `title`, `copyText` (copy something else, e.g. a reference number), `copyLabel`.

## Usage
Place under the page title or at the end of long guidance. Share uses the device share sheet where available and falls back to copying. The print stylesheet hides navigation and prints link URLs.
