# Quote

A quotation with attribution. Covers testimonials, the student voice panel and pull quotes.

## Props
| Prop | Type | Default | Notes |
|---|---|---|---|
| `children` | string \| node | — | the words |
| `cite` | string | — | who said it |
| `role` | string | — | context |
| `variant` | `'testimonial' \| 'student-voice' \| 'pull'` | `'testimonial'` | student-voice: navy speech shape, yellow mark |
| `label` | string | `'In their words'` | student-voice eyebrow |
| `image` | `{src}` | — | avatar; decorative |

## Usage
Only real quotes, used with consent. Never name or picture a child in care — attribute by age or year group ("Young person, Year 10"). Keep to 1–3 sentences.
