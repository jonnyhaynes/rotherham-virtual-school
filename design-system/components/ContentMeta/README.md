# ContentMeta

Publication metadata for guidance and documents: published, last updated, last reviewed, next review, owner — plus an optional content update notice.

## Props
`published`, `updated`, `reviewed`, `nextReview` (ISO dates, shown as "22 September 2026"), `owner`, `format`, `updateNotice` (`{date, text}`).

## Usage
Show at the top or foot of every guidance page. Use `updateNotice` only for changes a reader must act on; describe the change in one sentence. Covers publication metadata, last reviewed date, content update notice and document metadata.
