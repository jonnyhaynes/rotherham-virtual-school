# ConfirmationPanel

The confirmation state at the end of a form: a teal-700 panel with a tick, a title and a reference number.

## Props
`title` ('Form submitted'), `reference`, `referenceLabel` ('Your reference number'), `children`.

## Usage
Follow with what happens next and when, and how to get help. Use as the page `h1`. Offer `PageActions` with `copyText` set to the reference.

## GOV.UK
Themes `govuk-panel--confirmation` (teal instead of green, so success and error never rely on red vs green).
