# Tag

A short, non-interactive status label: one or two words beside a title.

## Props
| Prop | Type | Default |
|---|---|---|
| `tone` | `'neutral' \| 'teal' \| 'success' \| 'yellow' \| 'coral' \| 'purple' \| 'navy' \| 'error'` | `'neutral'` |
| `children` | text | — |

## Usage
Each tone pairs a -50 tint with its accessible text colour (5:1+). The word carries the meaning, never the colour alone. Don't make tags clickable — use `FilterPanel` or links.

## GOV.UK
Themes `govuk-tag`.
