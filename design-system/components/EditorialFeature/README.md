# EditorialFeature

A large two-column feature — media on one side, story on the other — for editorial features and case studies.

## Props
`title`, `eyebrow`, `text`, `image` (`{src, alt}`; defaults to a `BrandPattern`), `href`, `linkLabel`, `variant` (`'feature' | 'case-study'`), `facts` (`{term, value}[]`, case study), `quote`, `reverse`, `audience`.

## Usage
One per page section. Case studies are anonymised: no names, schools or photos of children in care. Stacks under 700px.
