# Template: Multi-step form

A working one-question-per-page journey — the pattern for multi-step forms, questionnaires and step-by-step wizards: ProgressIndicator, a ChoiceGroup whose legend is the `h1`, ErrorSummary + field error on "Continue" with no answer, a Check your answers page built from KeyFacts, and a ConfirmationPanel.

Rules: one question per page; Back link top-left; the button says "Continue" until the last step; validate on submit, not on blur; keep answers when going back.
