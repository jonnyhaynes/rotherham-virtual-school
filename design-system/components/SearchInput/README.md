# SearchInput

A labelled search form (`role="search"`) with a teal submit button.

## Props
`label` ('Search'), `hideLabel` (false), `placeholder`, `defaultValue`, `name` ('q'), `action` ('/search'), `onSubmit(query)`, `size` (`'default' | 'large'`), `inverse` (on navy).

## Usage
Keep the label even when hidden. Placeholder is never the only label. The header search uses `inverse`; the search page uses `large`.
