# Explainer

A short, visual answer to one big question — "What is a PEP?", "What is a virtual school?", "What is Pupil Premium Plus?" — with an icon, a one-sentence answer, up to four illustrated points and an optional 1–2 minute video. Built for the workshop's "less words, more images and diagrams".

## Props
`question`, `answer` (one sentence), `points` (`{icon, text}[]`, 2–4, a few words each), `icon`, `tone`, `audience` (tints the panel), `video` (VideoEmbed props), `href`, `linkLabel`, `headingLevel`, `id` (unique per page).

## Usage
Put the most-asked question near the top of each audience page. Keep points to five words or so. The full explanation lives on the linked page.
