# Tabs

Switches between a few related panels of content on one page.

## Props
`tabs` (`{id, label, content}[]`), `defaultTab`, `label` (tablist name), `title`.

## Accessibility
ARIA tabs: arrow keys move between tabs, Home/End jump, only the selected tab is in the tab order, panels are focusable.

## Usage
2–5 short labels. Only for content people don't need to compare side by side — otherwise use headings. Don't hide essential steps in tabs.

## GOV.UK
Equivalent to `govuk-tabs`; the list scrolls horizontally on narrow screens rather than becoming links.
