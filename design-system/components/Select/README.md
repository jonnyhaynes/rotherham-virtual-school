# Select

A native dropdown with label, hint and error. Props: `label`, `hint`, `error`, `options` (`{value, label, disabled?}[]`), `value`/`defaultValue`, `onChange`, `disabled`, `id`, `name`.

## Usage
Avoid when there are fewer than 7 options — use `ChoiceGroup` radios. Also used as the sort control in `FilterPanel`.

## GOV.UK
Themes `govuk-select`.
