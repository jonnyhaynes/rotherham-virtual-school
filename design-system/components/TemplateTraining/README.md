# Template: Training and events

**Route:** `/training-events/` (prototype `events` collection). Events from the prototype seed; videos are examples.

Composition: compact Hero, Tabs by audience ("tab based for groups") each holding EventCards or the prototype's "Nothing scheduled yet" empty state, a "Watch again" section of VideoEmbeds for recordings and short training videos, and Past sessions as QuickLinks. EventCard `status: 'recording'` tags a past session with a recording.

Workshop: "Events / training (recordings)", "1–2 minute videos for professionals, FC, SW", "training video shorts 10/15 mins", "tab based for groups".
