# Timeline

A chronological list of events or milestones with done, current and upcoming states.

## Props
`items` (`{date?, title, text?, status?: 'done'|'current'|'upcoming'}[]`), `label`.

## Usage
For history and dated sequences (a child's school year, the service's history). For instructions a reader follows, use `Steps`. States are also written out for screen readers ("completed", "current").
